# Skill: Dental Clinic Brand Design

## Purpose

Apply a consistent visual identity to the Dental Follow-up
application.

## Brand Personality

The interface should feel:

- Clean
- Calm
- Professional
- Trustworthy
- Modern
- Friendly

The application must not feel like a hospital system
or complex enterprise software.

## Color System

Primary:
Teal

Secondary:
Blue

Background:
Off-white / very light gray

Success:
Green

Attention:
Amber

Risk:
Red

## Typography

Use a modern sans-serif typeface.

Typography must prioritize readability over decoration.

## Components

Cards must use:
- Rounded corners
- Subtle borders
- Minimal shadows
- Comfortable spacing

Tables must be simple and easy to scan.

## Status Design

Green:
Normal / completed

Amber:
Requires attention

Red:
Risk of treatment abandonment

Color must never be the only way of communicating status.

Always combine status colors with text labels or icons.

## UX

The application is primarily used by a dental assistant.

Important operational information and actions must
be immediately visible without unnecessary navigation.
