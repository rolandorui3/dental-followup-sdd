# Dental Follow-up

Aplicación web para apoyar el seguimiento administrativo
de pacientes de un consultorio dental y reducir el riesgo
de abandono de tratamientos.

## Evolución del proyecto

Tarea 1:
Definición del problema.

Tarea 2:
Prototipo desarrollado mediante Spec Driven Development,
incluyendo contexto persistente, especificación del feature
principal y skill de diseño.

Tarea 3:
Evolución del producto a partir de una User Persona,
incorporación de una nueva SPEC y lanzamiento de una
versión funcional en producción.
