# Acceptance Criteria Validation

## AC1 - Lista de seguimiento
Status: PASS

Los pacientes identificados como riesgo aparecen en Seguimiento de hoy.

## AC2 - Información operativa
Status: PASS

Cada registro muestra paciente, tratamiento, días desde última sesión, prioridad, estado y acción.

## AC3 - Registro de contacto
Status: PASS

El estado puede cambiar de Pendiente a Contactado.

## AC4 - WhatsApp
Status: PASS

Los pacientes pendientes cuentan con una acción de contacto mediante WhatsApp.

## AC5 - Resolución
Status: PASS

El seguimiento puede cambiar a Resuelto y su representación visual se diferencia de los seguimientos activos.
